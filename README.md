# About KorvexCPU

## ISA (Instruction Set Architecutre)
 - ```nop``` - no operation
 - ```hlt``` - pause the cpu
 - ```add r1 r2 r3``` - add r1 and r2 and store it in r3
 - ```sub r1 r2 r3``` - sub r1 and r2 and store it in r3

## ALU (Arithmetic Logic Unit)

 - add
 - sub
 - xor
 - nor
 - and
 - rsh
